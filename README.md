# COSC 520 Assignment 2: Advanced Ordered Sets

A runnable **AI-generated reference project** comparing three manually
implemented advanced data structures: **AVL trees, randomized treaps, and
splay trees**. Each stores distinct signed 64-bit integer keys and supports
`insert`, `contains`, `delete`, and sorted iteration.

**Academic-use status:** this is not ready to submit unchanged. The assignment
requires your own contribution and disclosure of generated code. All supplied
code, tests, and documentation were initially generated by ChatGPT. No part is
claimed to be student-authored. Read [AI usage](docs/AI_USAGE.md), make substantive
changes, and record actual contributions in [the log](docs/CONTRIBUTIONS.md).

`set` and `sorted` appear only in correctness checks. Matplotlib only draws plots.

## 1. Setup

Use Python **3.10 or newer**. Run all commands from this folder, the folder
containing this README. You do not need to install this package to run it.

Windows PowerShell:

```powershell
py -3 --version
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

If `py` is unavailable but `python --version` works, use `python` instead of
`py -3`. If Windows says Python was not found, install Python with the Python
launcher, restart PowerShell, and confirm the version before creating a venv.
Calling the venv executable directly avoids PowerShell activation-policy issues.

macOS / Linux:

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

The following commands use `python`. On Windows you can replace it with
`.\.venv\Scripts\python.exe`; on Linux/macOS use your activated environment.
Plotting is optional: all algorithms, tests, dataset tools, and benchmarks run
with the standard library alone.

## 3. First benchmark

```bash
python -m experiments.benchmark --config configs/quick.json --output results/quick
python -m experiments.plot --results results/quick
```

This profile compares all three structures at 1,000, 5,000, 10,000, and
20,000 keys, using uniform, hotspot, and sequential search workloads, with
three repetitions. It performs 108 isolated jobs.

Outputs:

- `raw.csv`: every measured repetition, operation counts, checksums, time, memory.
- `summary.csv`: medians and observed min/max values.
- `performance_table.md`: a measured table to use when preparing your report.
- `metadata.json`: environment, configuration, source hash, dataset manifests.
- `plots/`: PNG and vector PDF figures for timings, total build time, and storage.

Result files are protected from accidental overwrite. Resume an interrupted
run with the same command plus `--resume`; it refuses changed source, config,
or interpreter/platform metadata. Use a new output folder after changing code.

## 4. Large-scale experiments

```bash
python -m experiments.benchmark --config configs/full.json --output results/full
python -m experiments.plot --results results/full
```

The full profile has eleven sizes, ending at **10,000,000 distinct keys**,
three repetitions, random insertion, and uniform search. It performs 99 jobs.
It deliberately limits the workload matrix to keep the largest runs practical.
`configs/standard.json` tests three insertion orders and three search workloads
up to one million keys; it performs 648 jobs and is also expensive.

Ten-million-node Python tree construction can take substantial time. Run the
quick profile first and leave the full profile running on a suitable computer.
This workload is CPU-bound and does not require a GPU. Arrays use approximately
20/24/28 bytes per allocated node for splay/AVL/treap payloads, respectively,
plus capacity, headers, dataset storage, and experiment overhead. Those payload
estimates are not whole-process memory measurements.

**Verification scope:** bundled sample measurements are small-scale; separate
scale checks reach one million keys with one repetition. The
ten-million-key dataset was generated and checked, but the complete full
benchmark profile has not been run during project creation. Do not label the
sample plots as ten-million-key results. See `docs/VALIDATION.md` for performed
checks and measured scale.

## Python API

```python
from structures import AVLTree, Treap, SplayTree

tree = AVLTree()                    # Treap(seed=42) or SplayTree() also works.
assert tree.insert(10) is True
assert tree.insert(10) is False      # Set semantics: no duplicate key.
assert tree.contains(10) is True
assert tree.delete(10) is True
assert tree.delete(10) is False
assert list(tree.inorder()) == []
tree.validate()                     # Debug check, outside measured timing.
```

`SplayTree.contains` changes the shape, including on a miss. Do not mutate a tree
while consuming its `inorder()` generator. Trees are single-threaded. They store
keys, not arbitrary values. Deleted array slots are recycled; arrays do not
shrink immediately after deletion.
