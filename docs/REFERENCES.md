# Verified algorithm references

The implementations in this package were generated for this project; they were
not copied from the code on these pages. These sources support the design and
theoretical explanations. The assignment itself was read from the supplied PDF
and is deliberately excluded from the public project package.

1. Cornell University, CS 2112 lecture notes, **AVL trees** (Fall 2021).
   https://courses.cs.cornell.edu/cs2112/2021fa/lectures/avl/index.html
   Covers rotations, AVL height bounds, and the Fibonacci recurrence.
2. James Aspnes, Yale University, **Randomized Search Trees**.
   https://www.cs.yale.edu/homes/aspnes/pinewiki/RandomizedSearchTrees.html
   Covers randomized BST shapes, priorities, treaps, and expected depth.
3. Daniel D. Sleator and Robert E. Tarjan, **Self-Adjusting Binary Search Trees**,
   Journal of the ACM 32(3), 652-686, 1985.
   Author-hosted paper: https://www.cs.cmu.edu/~sleator/papers/self-adjusting.pdf
   Author-hosted bibliographic page: https://www.cs.cmu.edu/~sleator/papers/Self-Adjusting.htm
   Provides the amortized analysis for splay trees.
